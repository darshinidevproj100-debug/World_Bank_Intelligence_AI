## Verified source documentation

- WDI uses the official [Indicators API v2 basic call structure](https://datahelpdesk.worldbank.org/knowledgebase/articles/898581-api-basic-call-structures).
- The World Bank describes the [Projects API](https://blogs.worldbank.org/en/opendata/first-steps-in-integrating-open-data) and lists Projects and Finances APIs in its [developer API overview](https://datahelpdesk.worldbank.org/knowledgebase/articles/889386-developer-information-overview). The project does not yet depend on the older example query as a production contract.
- Documents & Reports documents its [search API](https://documents.worldbank.org/en/publication/documents-reports/api). The remote adapter is not yet implemented.
- Finances One dataset pages expose dataset-specific API services and downloads; for example, [IBRD Country Exposures](https://financesone.worldbank.org/d/DS04621). No single dataset has been selected for this project, so the generic CSV adapter requires caller-supplied verified columns.

## JEV audit

The repository contains no formal JEV definition or implementation. The project prompt explicitly says to avoid inventing it. Routing therefore remains the named, transparent keyword baseline; R22 is blocked pending the authoritative definition or reference.
